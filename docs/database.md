# Database

## Overview

Spendly uses Drift ORM on top of SQLite. Every read and write goes through Drift — there is no raw SQL in feature code. The database lives on-device and is the single source of truth for all app data.

---

## Why Drift

- Type-safe queries — compile errors instead of runtime crashes
- Stream-based watching — changes in the DB automatically push updates to the UI via Riverpod
- Code-generated DAOs — no boilerplate mapping between rows and Dart objects
- SQLite — fast, zero-configuration, works fully offline

---

## Schema

The database has 14 tables (schema version 22). All monetary amounts are stored in paise (1 ₹ = 100 paise) to avoid floating-point precision errors. All mutable entities support soft deletes via an `isDeleted` flag. Timestamps are stored as Unix epoch milliseconds (integers).

---

### transactions

Stores every income, expense, and investment event.

| Column | Type | Notes |
|---|---|---|
| id | TEXT (UUID) | Primary key |
| type | TEXT | `income`, `expense`, or `investment` |
| amount | REAL | Display amount (₹) |
| amountPaise | INTEGER | Exact amount in paise |
| categoryId | TEXT | FK → categories.id |
| paymentMode | TEXT | `cash`, `card`, `upi` |
| cardType | TEXT | `credit` or `debit` (optional) |
| date | INTEGER | Transaction date (Unix epoch ms) |
| note | TEXT | Optional description |
| createdAt | INTEGER | Row creation timestamp |
| updatedAt | INTEGER | Last update timestamp |
| recurringRuleId | TEXT | FK → recurringRules.id (null if not recurring) |
| isRecurringInstance | BOOLEAN | True if auto-generated by a recurring rule |
| isDeleted | BOOLEAN | Soft delete flag |

## Data Flow

```text
User action (UI)
      ↓
Riverpod Provider calls Repository method
      ↓
Repository calls Drift DAO (insert / update / select)
      ↓
Drift executes SQL on SQLite file on device
      ↓
Drift stream emits updated rows
      ↓
StreamProvider pushes new value
      ↓
Widgets rebuild automatically
```

---

## Offline-First Guarantee

All reads and writes hit the local SQLite file. There is no network call in the data path. Cloud sync (Google Drive) is a separate background process that copies a JSON snapshot; it does not replace the local database as the source of truth.
